# T1.7 — NURSE role reality check + DOCTOR/DENTIST naming mismatch

**Status:** ✅ DONE (static) · **Size:** S · **Priority:** 🟠
**Source:** ROLE_BENCHMARK.md §0 note; §4.3; BUSINESS_FLOW_SOURCE.md §J8, Final §4.
**Verdict:** ❌ F1-007 (NURSE no clinical grants) · ❌ F1-004 (DOCTOR/DENTIST functional break) · role enum duplicated 3×

## Results (08/07/2026)

**NURSE (F1-007):** zero controller `@Roles` include NURSE. Only reachable surface is via
service-layer allowlists: appointment create/list/**check-in** (`appointments.service.ts:287`),
patient-representatives (`service.ts:248`), payments (`payments.service.ts:72`). Seed grants only
`patient:read, appointment:read` (`run-user-seed.ts:178`). → Nurse **cannot** record vitals into an
examination session (J2 wants this) and cannot draft clinical notes. Cannot diagnose/prescribe/sign
✅ (correct). Being allowed to check-in + pass payment ops contradicts §I2/§K (Receptionist domain).

**DOCTOR/DENTIST (F1-004):** confirmed functional, not cosmetic:
- Backend `RoleEnum` = `ADMIN, DOCTOR, PATIENT, RECEPTIONIST, NURSE` (`account.ts:12-18`). JWT
  carries `role: account.role` → `"DOCTOR"`.
- Frontend `roles.ts` has `DENTIST` (no `DOCTOR` key), plus `CLINIC_ADMIN`, `SUPER_ADMIN`.
  `CLINICAL_ROLES = ["DENTIST","CLINIC_ADMIN"]`; `config/navigation.ts:21-42` gates on `"DENTIST"`.
- `auth.ts:56` sets `user.roles = ["DOCTOR"]`. `ProtectedRoute`/nav checks that need `"DENTIST"`
  therefore fail for a real doctor. `resolveDashboardKind` (nav.ts) is the only place that maps both
  → dashboards resolve, but clinical role-list gates don't.

**Role enum duplicated in 3 places (drift risk):** `iam-service/accounts/domain/account.ts`,
`clinical-emr/auth/roles/roles.enum.ts`, `payment-service/auth/roles.enum.ts`. Values currently
consistent (no DENTIST in any), but no single source of truth.

**Recommendation:** (a) pick one canonical role vocabulary — either add `DOCTOR` alias in FE and
retire `DENTIST`, or map at the auth boundary; (b) decide whether NURSE should get
`examination:write(draft)` per J2; (c) extract shared role enum.
